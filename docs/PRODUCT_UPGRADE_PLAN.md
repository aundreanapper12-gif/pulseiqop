# PulseIQ Product Upgrade

This branch adds the 14-day trial conversion layer and turns the existing workspace into a stronger recurring product experience.

Planned in this upgrade:
- 14-day no-card trial state and countdown
- Guided onboarding
- Executive dashboard / PulseIQ Score
- Industry-aware guidance
- Scenario simulator
- Recovered-profit tracking surfaced more prominently
- Ask PulseIQ decision helper
- Referral sharing
- Trial-to-paid conversion CTAs
- Pricing/homepage positioning updates

Cloud account authentication and cross-device persistence require an external auth/database provider and production credentials. The UI will clearly distinguish browser-local trial data from cloud accounts until that backend is connected.
